## 格式与边界

五架虚拟无人机同时从 100% 开始，分别在 20% 进入降落阶段。电量只取整数；0.1 秒采样；同一随机种子可重现，不同种子有随机差异。

保留真实 logger 原来的 62 列，另加 `is_simulated`、`data_origin`、`simulation_model`、`simulation_seed` 等来源列。所有 ID 以 `SIM_` 开头，没有加入实验数据库。

已生成的内容：SOC、仿真时间、条件标签、目标 Mission Pad、目标坐标、示意起飞/回正/悬停/降落阶段。

**未生成实测坐标、姿态、温度、速度、加速度等传感器值：对应列为空。** `timestamp` 和 `drone_ip` 也为空，避免把虚拟运行说成实际发生过。目标坐标不等于实测坐标。示意起飞、回正、降落各 3 秒属于假设。

电池对应 D1/B11、D2/B10、D3/B13、D4/B14、D5/B12。未标定 B06 的实测记录不冒充 B12。几何读取当前代码中的纯布局函数，未连接无人机。

## 随机性与用途

每块电池的三阶段 baseline 作为参照，由真实 wind tunnel 的掉电片段学习局部耗电速度。使用整次飞行的共同波动、各电池跨阶段偏差和连续局部误差片段进行随机模拟，而非把 Medium 按固定比例复制到 High/Low。

整程公共随机偏差不采用只有一两架机、几个片段的短记录。正常掉电间隔在开发集各阶段 0.5%–99.5% 分位范围内；初始电量平台单独抽样。此限制针对常规悬停，不再现故障和传感器异常尾部。

未测条件扩大随机偏差只是敏感性假设，不是物理正确性的保证。没有强制 leader 最耗电或间距越近耗电必然更大。前进 2.5 m 的 Medium 耗电率没有直接套到悬停上。

模型在留出条件上的已观测片段总耗时平均绝对百分比误差约 21.1%，中位数约 9.5%。这不是完整飞行时长准确率。可用于算法开发和敏感性分析，不能替代真实实验或作为独立实测验证集。
